# M5 checkpoint — App Server and CLI skeleton

Status: **passed**

Date: 2026-09-01

Scope: local, single-user Rust process and transport skeleton. Durable state, the security kernel,
the agent loop, remote/VPS authentication, HTTP/WebSocket and Telegram Web App integration remain
later migration phases.

## Outcome

The production Rust workspace now builds a `cool` binary with `app-server`, `serve`, `run` and
`doctor` routing. The App Server negotiates generated App Protocol v1 over bounded stdio or a local
Unix socket/Windows named pipe, creates ephemeral sessions, streams canonical echo-run events and
supports cancellation plus cursor catch-up. It deliberately contains no LLM, tool, approval,
policy or durable-storage implementation.

## Deliverables

- `cool-app-server` and `cool-cli` production workspace crates.
- Generated JSON-RPC command/response contract shared by Rust and both TypeScript consumers.
- Initialize/capability negotiation with advertised frame, RPC-id, concurrency, queue and page
  limits.
- Stdio plus user-local Unix socket/Windows named-pipe transports.
- Bounded input/output frames, in-flight work and outbound delivery/write deadlines.
- Actor-scoped mutation idempotency, one-active-run session lifecycle and reason-preserving
  cancellation.
- Byte-aware event replay pagination and reconnect/catch-up without repeated side effects.
- Fail-closed unsupported multimodal content and later-phase command routes.
- TypeScript child-process sample that launches the real `cool app-server` binary.
- Cross-platform debug/release CI, generated-artifact drift gate, Dependabot and `cargo-deny`
  policy.

## Residual boundaries

- Sessions, runs, events and idempotency indexes are process-local and disappear on restart. M6
  owns durable state and recovery.
- Identity is fixed to `local-user`; no TCP listener, remote authentication, multi-user isolation or
  VPS/Telegram exposure is safe or supported yet.
- Prompts are text-only deterministic echoes. LLMs, tools, approvals, artifacts and policy belong to
  later phases.
- Linux and macOS are represented by CI configuration; only Windows execution was verified locally.
- The replay preflight models M5's fixed-size identifiers/timestamps and short event sequences.
  Durable/high-volume event forms introduced later must retain serialized-frame boundary tests.
- `ts-rs` reports that it does not interpret Serde's `deny_unknown_fields`; Serde/schema strictness
  remains enforced and covered by protocol tests.
